# Riuna

Riuna is a self-hosted, all-in-one productivity platform: project and task
management first, with a light CRM and ERP planned later. It is a hard fork
of [Kaneo](https://github.com/usekaneo/kaneo) (MIT), maintained as an
independent, internal program. See [`NOTICE`](NOTICE) for attribution and
[`AGENTS.md`](AGENTS.md) for the full operating guide.

**What it is:**
- **Clean interface** that focuses on your work, not the tool
- **Self-hosted** so your data stays yours
- **Open source** under a permissive MIT license

## Getting Started

### Quick Start with Docker Compose

The fastest way to try Riuna is with Docker Compose. See [`compose.yml`](compose.yml)
for the single-container setup (Riuna + PostgreSQL).

Copy `.env.sample` to `.env`, set `RIUNA_CLIENT_URL=http://localhost:5173`,
`POSTGRES_PASSWORD=<password>`, and `AUTH_SECRET=<output of openssl rand -hex 32>`,
then run:

```bash
docker compose up -d
```

and open [http://localhost:5173](http://localhost:5173).

In Docker Compose, the bundled container reaches PostgreSQL at the service
hostname `postgres`. If you run the API on your host instead of inside
Compose, use `localhost` or set `DATABASE_URL` explicitly.

### Deploy on Coolify

Riuna ships a [Coolify-optimized `compose.coolify.yml`](compose.coolify.yml).
In Coolify, create a resource pointing at this repository, pick the
**Docker Compose** build pack (Base Directory `/`, Compose Location
`compose.coolify.yml`), assign a domain to the `riuna` service as
`https://your-domain.com:5173`, set `RIUNA_CLIENT_URL`, and deploy.
`AUTH_SECRET` and the database password are auto-generated by Coolify. Leave
`RIUNA_API_URL` unset (it is derived from `RIUNA_CLIENT_URL`; a `localhost`
value breaks the browser API calls).

### Development Setup

See [`ENVIRONMENT_SETUP.md`](ENVIRONMENT_SETUP.md) for configuring
environment variables and troubleshooting common issues like CORS problems.

Quick start:
```bash
pnpm install

# Create a .env file in the root with required environment variables
# See ENVIRONMENT_SETUP.md for detailed instructions

# Start development servers
pnpm dev
```

For contributing guidelines, code structure, and development best practices,
see [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`AGENTS.md`](AGENTS.md).

### Configuration

Riuna requires several environment variables to be configured. The Docker
Compose setup above handles the database automatically, but you'll need to
configure environment variables for the API and web services — see
[`ENVIRONMENT_SETUP.md`](ENVIRONMENT_SETUP.md) for the complete list.

## Kubernetes Deployment

A Helm chart lives in [`charts/riuna`](charts/riuna/README.md), with
installation instructions, production configuration examples, and TLS setup.

## MCP Server

Every instance ships a built-in HTTP MCP endpoint at `/api/mcp`, so AI tools
like Claude, Cursor, and other MCP clients can manage tasks, projects, and
labels. For stdio clients there is also the [`@riuna/mcp`](packages/mcp)
package, built from source (see its own README).
